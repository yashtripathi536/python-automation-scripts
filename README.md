Python Automation Scripts

About the Project

This repository contains Python automation scripts created to automate simple and repetitive tasks.

Project Files

- "python_script_automation.py" – Main Python automation script.
- "input.txt" – Input data required by the script.

Technologies Used

- Python
- File handling
- Python automation

How to Run

1. Install Python on your computer.

2. Download or clone this repository.

3. Open the project folder in a terminal.

4. Run:
   
   "python python_script_automation.py"

5. Follow the instructions displayed by the script.

Purpose

The purpose of this project is to learn Python automation and reduce manual work through scripting.
